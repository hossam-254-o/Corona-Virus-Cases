# 🌍 Global COVID-19 Cases Analysis Dashboard

An interactive **Power BI** dashboard tracking and analyzing **COVID-19 cases, recoveries, and mortality rates** worldwide. This project transforms global pandemic records into clear, interactive visual insights to monitor infection waves, regional impacts, and country-level trends over time.

---

## 🎯 Project Overview
Visualizing epidemiological data at a global scale helps clarify the spread, severity, and progression of the pandemic across regions. The objective of this project is to:
* Track key global pandemic KPIs including **Total Confirmed Cases**, **Total Deaths**, **Total Recoveries**, and **Active Cases**.
* Compare infection rates and mortality ratios across **countries and continents**.
* Visualize daily and monthly case trajectories to highlight peak waves and recovery trends.

---

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** Interactive dashboard design, geospatial mapping, and visual storytelling.
* **Power Query (M):** Data cleaning, handling missing values, and ETL transformations.
* **DAX (Data Analysis Expressions):** Custom measures for Total Cases, Recovery Rate %, Mortality Rate %, and cumulative totals.

---

## 🔄 Data Preprocessing & Modeling
To prepare the global health dataset for accurate geospatial and time-series reporting, the following steps were executed:
1. **Data Cleaning & Standardization:** Standardized country names, resolved null values, and formatted date columns using **Power Query**.
2. **Geospatial & Time Modeling:** Configured geographic data categories for interactive map visuals and built date hierarchies for timeline filtering.
3. **KPI & Measure Development:** Created dynamic **DAX** measures to compute case fatality rates, recovery percentages, and country-level rankings.

---

## 📈 Key Analytical Highlights & Insights
* **Global & Regional Distribution:** Used interactive maps and bar charts to identify the most affected countries and continents by confirmed cases and fatalities.
* **Recovery vs. Mortality Ratios:** Evaluated healthcare outcomes across regions by comparing recovery rates against mortality percentages.
* **Timeline Progression:** Tracked the evolution of confirmed cases over time to highlight major global surges and stabilization periods.
